How to Update the W225 Timeline

All task dates live in one spot near the top of this file. You don't need to know how to code — just find the task, change the date, and save. Here's how:

Step 1 — Open the file on GitHub

  1. Go to github.com/leeroy-cmyk/reports
  2. Click on w225_timeline.html
  3. Click the pencil icon (✏️) in the top-right of the file view

Step 2 — Find the task you want to change

  1. Press Ctrl+F (or Cmd+F on Mac) to open search
  2. Type the task name — for example: Water Heater or 3rd Floor Paint
  3. Each task looks like this:
{name:'Water Heater Install', start:null, end:'2026-06-30'},

Step 3 — Change the date

Dates use the format YYYY-MM-DD. Just replace the date string:

BeforeAfter (moved 2 weeks)
end:'2026-06-30'end:'2026-07-14'
start:'2026-05-11'start:'2026-05-25'
No start date? If a task shows start:null leave it as null — the chart will show a milestone diamond on the due date instead of a bar.
No dates yet? Leave both as null — it shows "date TBD" on the chart.

Step 4 — Mark a task complete

Add done:true to the task and it will turn green with a checkmark:

{name:'Atlas Boiler Install', start:null, end:'2026-06-15', done:true},

Step 5 — Save your changes

  1. Scroll to the bottom of the GitHub editor
  2. In the Commit changes box, type a brief note like: Update plumbing dates
  3. Click Commit changes — the live site updates in ~60 seconds
