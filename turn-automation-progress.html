The turn pipeline

Each stage a turn goes through, from a resident giving notice to the unit being ready to rent.

1
Detect move-outs & notices
Local daily run

Done

  • Reads AppFolio vacancy daily; finds Spokane units that moved out or gave notice
  • Turn start date = move-out + 1 day
  • 100% AppFolio ↔ PropertyMeld unit matching

To finish

  • Runs as part of your schedule spokane turns command — not yet a cloud cron (see Next Steps #1)
2
Create the turn project
Local daily run

Done

  • Creates the "Standard Unit Turn" (7-meld template) in PropertyMeld for any unit missing one
  • Skips units that already have an open turn

To finish

  • Uses only PropertyMeld + AppFolio APIs (no 2FA) — ready to move to the cloud so it runs hands-off (Next Steps #1)
3
Dedupe duplicate turns
Automated · cloud

Done

  • If a unit has more than one open turn, keeps the canonical one and neutralizes the duplicate
  • Runs first in the daily cloud job — stops double-booking at the source

To finish

  • Nothing — complete
4
Schedule in-house work (Ron & Michael)
Automated · cloud

Done

  • 2 paint days + 1 maintenance day per turn (one tech per unit) + 1-hr initial walkthrough
  • Mon–Thu 8a–4p, densely packed, never double-books
  • Append-only — never moves work already on the calendar
  • Priority: leased → Converted → Converting → vacancy % → rent

To finish

  • Only 2 turn techs — near-term calendars fill fast, so new turns can land weeks out
  • Spokane only (Tri-Cities not yet automated — Next Steps #5)
5
Final walkthrough (quality check)
Automated · cloud

Done

  • Scheduled to David Sanchez, the day after the last vendor task (carpet, else cleaning)
  • Runs daily in the cloud job

To finish

  • Lands most precisely once vendor dates are set automatically (depends on Stage 6)
6
Schedule vendors (cleaning, carpet, flooring)
Pending

Done

  • The Turns report shows suggested cleaning & carpet dates (clean = last in-house + 3 business days; carpet = next day) so the manager can book vendors

To finish

  • Auto-booking not built — the vendor "assign + set date" API hasn't been captured yet
  • Vendors: SPO Cleaning · Allklean (carpet) · Inland Pacific (flooring)
7
Set AppFolio available date
Local · cloud blocked

Done

  • Sets Available = Ready-to-Show, Rent Ready = No; date = final walk + 3 days (interim: maintenance + 7)
  • Ratchet — dates only move earlier, never later
  • Runs in your daily af_daily local command

To finish

  • Can't run in the cloud — AppFolio login needs SMS 2FA, which blocks a headless cron (Next Steps #4)
8
Handle cancelled / changed move-outs
Pending

Done

  • Changed move-out date → turn start shifts, new work added (append-only)
  • Rule set: a cancelled move-out deletes the turn completely and frees its slot
  • Cleanup script built & dry-run ready (pm_cancelled_turn_cleanup.js)

To finish

  • Not yet wired into the daily job — needs one dry-run review, then activation (Next Steps #2)

Next steps

In priority order.

1
Move turn detection & creation to the cloud High
Stages 1–2 use only PropertyMeld/AppFolio APIs (no 2FA), so they can run hands-off in the daily cloud job. Then the only thing needing your local run is the AppFolio date write.
2
Activate cancelled-move-out cleanup High
Run the built script as a cloud dry-run, review the flagged turns, then add it as the first step of the daily workflow so cancelled turns are removed and their slots backfilled automatically.
3
Automate vendor scheduling Medium
Capture the PropertyMeld vendor assign/schedule API, then auto-book cleaning → carpet → flooring. This also lets the final walkthrough land on an exact date instead of a suggestion.
4
Get the AppFolio date write into the cloud Medium
Resolve the SMS-2FA blocker (trusted device / app token), or formalize it as the one daily local click. Until then Stage 7 stays local.
5
Expand beyond Spokane Later
Bring Tri-Cities (and Tacoma) turns into the same create → schedule → publish pipeline.
6
Backlog cleanup Later
Cancel stale / duplicate open turns and mark finished-but-still-open turns complete so counts and the calendar stay clean.
